\section{Why the obvious approaches fail}
\label{sec:why}
\budget{0.75 pp}

\note{THREE LEGS. This section replaces a conventional related-work paragraph
and is stronger than one, because each leg has a consequence you can point at.
Roughly one paragraph each.}

\note{\textbf{Leg 1 --- coverage-maximising formalisers stub the uncomputable
node, and that is unsafe in the direction that matters.} PathWISE-style systems
replace a predicate they cannot compute with \texttt{false}. Show the measured
consequence here and forward-reference the ablation. This is the leg that earns
Figure~\ref{fig:stub} if you have room for it.}

\note{\textbf{Leg 2 --- sampling-disagreement does not detect vagueness.} This
is a genuine negative result about a prior method and you already ran it:
20 statements $\times$ K{=}8 samples; all 80 samples of the vague statements were
REFUSED, and 0 statements produced more than one semantic reading. The premise
is that a vague statement admits several readings which disagree; in practice
the model does not produce several readings, it produces eight refusals. So
separation comes from refusal, not from disagreement --- one constrained decode
does what a K-sample ambiguity estimator was supposed to, at an eighth of the
cost. K$>$1 survives only as a confidence estimator, because a risk--coverage
curve needs a score. \textbf{Foreground this one.} It is the most quotable thing
in the paper and it costs you three sentences.}

\note{\textbf{Leg 3 --- asking a model ``is this vague?'' is circular} and weak
even when purpose-built (cite the $\sim$0.71 F1 error-categorisation result).
So the gate aggregates evidence the earlier stages already produced, and only
then asks a model to encode. BE PRECISE HERE --- see \S\ref{sec:residue} and
Table~\ref{tab:attribution}: two of six reason codes are reachable without a
model. Do NOT write ``most of the decision is made deterministically''; that
claim was false and is now pinned false by a test.}

The four constrained calls, one sentence each:
\begin{itemize}
  \item the recommendation classifier must return a verbatim quote, checked as a

  \item the mention proposer returns exact substrings of the sentence;
  \item the terminology selector returns an INDEX into a candidate list, or
        abstains --- a hallucinated code is not expressible;
  \item the rule decoder's variable enum is the registry, so an unknown name
        cannot appear.
\end{itemize}

\section{What the residue turns out to be}
\label{sec:residue}
\budget{0.5 pp}

\note{FOUR NUMBERS, EACH WITH ITS CAVEAT INLINE. Frame them as properties of
GUIDELINES, not as scores for your system.

\textbf{Provenance caveat, stated FIRST and in your own voice:} this pass was
labelled by the same model family that produces the encodings, is therefore not
independent, and is reported as a pilot. Saying it yourself converts your
biggest vulnerability into a credibility signal. Do not bury it in limitations.

\begin{itemize}
  \item \num{27\%} of extracted spans are not recommendations at all --- so any
        coverage figure computed over raw extracted spans is not comparable
        across papers. THIS IS YOUR MOST USEFUL CONTRIBUTION TO THE FIELD and it
        is currently buried; give it its own sentence.
  \item Ceiling of \num{12/33 = 36\%} on real recommendations, and only
        \num{1 of 21} refusals is \texttt{beyond\_dsl} --- expressiveness is
        almost never the binding constraint. Vagueness and non-patient-level
        content are. Adding DSL operators would buy close to nothing.
  \item \num{15\%} of real recommendations are permissive, and every one is
        misreported as a violation by anything that lowers to CQL and reads
        \texttt{Violated}.
  \item One guideline in the corpus is essentially 100\% defeasible --- and only
        a system willing to return zero can report that.
\end{itemize}

\num{Numbers in orange are unverified against the current code.} Re-run before
you submit; several of them predate fixes that moved the denominator.}

\section{Limitations, and what a reviewer can run}
\label{sec:limits}
\budget{0.25 pp --- flat, no hedging}

\note{SHORT AND BLUNT. Reviewers reward this and it costs almost nothing.
\begin{itemize}
  \item \texttt{cql-to-elm} has never run, so ``compiles'' means brackets balance
        and names resolve. Nothing has executed against a FHIR bundle.
  \item No clinician has adjudicated anything. The gold labels are ours.
  \item Corpus is 9 open-access guidelines; PMC OA over-represents journals that
        publish structured recommendation abstracts. NICE, KDIGO and ACC/AHA are
        not open access. State the sampling frame.
  \item Physiological ranges are the caller's to supply and the live pipeline
        supplies none, so on a Track A rule the unit-slip warning cannot fire and
        the solver may return a counterexample at eGFR = 2.0. (Small fix: a
        lookup table keyed by binding code, threaded into one call.)
  \item There is no reference corpus with ground truth for this task. AHRQ CDS
        Connect is not a rules artefact and eCQMs are cohort definitions rather
        than recommendations. \textbf{This is a finding, not an apology} --- one
        sentence, and it pre-empts ``why didn't you evaluate against X''.
\end{itemize}}

\note{END ON THE REPRODUCIBILITY LINE --- it is a genuine asset and almost
nobody offers it: \texttt{cassette.py} + \texttt{test\_replay.py} record one real
run's model responses and replay the full pipeline offline, so a reviewer can
reproduce the pipeline WITH NO API KEY. A stale tape skips rather than passes.
\begin{verbatim}
python3 test_dsl.py && python3 test_bind.py && python3 test_segment.py \
  && python3 test_gate.py && python3 test_cql.py    # offline, no key
python3 test_replay.py                              # replays a real run
\end{verbatim}}
